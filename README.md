# TwinPulse Health Twin

Build TwinPulse — An Uncertainty-Aware Personal Health Digital Twin

Act as a senior healthcare product designer, frontend engineer, and AI prototype developer. Build a polished, responsive, functional healthcare research prototype named **TwinPulse**.

Follow all requirements in the attached specification:
- Project Vision: Virtual representation of health state using time-based measurements, trends, illustrative risk scores, what-if simulations, and uncertainty/freshness awareness. Educational research prototype, not a medical device.
- Visual Design: Premium medical research platform theme (#F5F8FC bg, #2457D6 deep blue, #12A89D teal, #15243B dark navy, Inter font, clean cards and subtle borders/shadows).
- Layout: Collapsible sidebar (Overview, Patient Twin, Health Timeline, Risk Analysis, What-If Simulator, Data Quality, Dataset & Validation, About TwinPulse), top bar with status badges and patient selector.
- Features: Interactive charts (Recharts), working timeline, transparent deterministic risk scoring separate from data reliability, interactive what-if simulation with before/after comparisons, data quality/staleness tracking, CSV export/import with validation, local storage persistence, and comprehensive disclaimers.
